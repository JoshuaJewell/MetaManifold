# MetaManifold v0.1.0

## What MetaManifold is

MetaManifold is a self-hostable platform for amplicon microbiome analysis by
metabarcoding. It composes established command-line tools of the field
(cutadapt, DADA2, SWARM, VSEARCH, cd-hit-est) into a single configurable
pipeline, stores per-run results in DuckDB, and presents them through an
interactive web interface. It gives particular attention to eukaryotic data
(18S amplicons classified against PR2) and treats comparison across sequencing
runs as a priority operation.

This first release exists to provide a fixed, dependency-pinned point that
other researchers can install, run, reproduce, and cite in their own work.

## Highlights

- End-to-end amplicon orchestrator in Julia: cutadapt, DADA2, SWARM, vsearch,
  and cd-hit-est composed under a single configurable pipeline, with per-run
  and cross-run DuckDB results.
- Interactive React/Plotly frontend for studies, runs, composition, alpha
  diversity, NMDS, PERMANOVA, cross-run comparison, and a Venn / UpSet view.
- Functional annotation layer (`funcdb`) that matches taxa across a
  eukaryote-aware rank hierarchy (PR2, from species up to supergroup), derives
  a dual-classifier consensus rank and confidence score where VSEARCH and DADA2
  agree, and supports auditable manual curation through an append-only ledger.
- AGPL-3.0 licensed; CI on GitHub Actions; coverage tracked on Codecov.

## Reproducibility

- Julia dependencies pinned in `Manifest.toml`.
- R dependencies (DADA2, vegan, and their transitive chain) pinned in
  `renv.lock`; restore with `renv::restore()` from the repository root.
- Citation metadata in `CITATION.cff`.

## How to cite

This release is archived on Zenodo; cite the concept DOI minted for the tag
together with the upstream tool citations listed under `references:` in
`CITATION.cff`.
